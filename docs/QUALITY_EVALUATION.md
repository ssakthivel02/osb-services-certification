# Certification Quality Evaluation

## Functional evidence

- Issue, verify, suspend, revoke, expire and reissue paths
- Deterministic canonical payload and signature verification
- Idempotent retries without duplicate credentials
- Correct version and key selection

## Security evidence

- Cross-tenant and role-bypass negative tests
- Key export and key-version misuse prevention
- Tampered payload, signature and QR rejection
- Revoked and expired certificate rejection
- Public verification data-minimisation review

## Reliability evidence

- Revocation propagation latency
- Verification availability and bounded cache behaviour
- Backup/restore reconciliation of certificate and audit state
- Alerting for signing, verification and audit failures

## Inclusive experience

Certificate and verification interfaces require keyboard operation, screen-reader labels, meaningful status text, accessible documents, and reviewed English and Tamil content.
