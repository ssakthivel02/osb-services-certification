# Production Readiness Gate

Production remains NO-GO until evidence exists for:

- Running versioned issue, verify, revoke and download APIs
- Authentication, role authorisation and cross-tenant negative tests
- Managed KMS/HSM signing with tested rotation and compromise response
- Canonical signature verification across supported clients
- QR allow-list and tamper tests
- Idempotent issuance and duplicate-prevention tests
- Revocation propagation and stale-cache tests
- Minimal-disclosure privacy review
- English and Tamil content review
- Accessibility validation for certificate and verification views
- Load, resilience, backup and restore tests
- Metrics, alerts, dashboards and operational ownership
- Security review and documented rollback decision
